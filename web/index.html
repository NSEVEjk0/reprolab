Replay runs this candidate in another gVisor sandbox against the recorded cases. It requires the pinned image and runtime. An evidence hash checks integrity; it does not attest the controller or host.

    

    
A FIX YOU CAN INSPECT
Code in a box.
Answers outside it.
A repair should come with more than a confident explanation. ReproLab keeps the acceptance decision outside generated code and makes the evidence portable.
01 /
Prove there was a failure
The original source must produce a real mismatched result or caught error through the worker protocol.
02 /
Give the repair a fresh check
The candidate sees inputs, never the checker’s expected outputs. New cases are generated for each evaluation.
03 /
Keep the useful limits visible
Passing these cases is finite test evidence. It is not proof for every possible input or a security audit.
